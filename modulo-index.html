1. Introducción a la Programación

La programación es el arte de dar instrucciones a una computadora para resolver problemas. Todo comienza con un **algoritmo**, que es una secuencia de pasos lógicos y precisos. Estos algoritmos, una vez escritos en un lenguaje de programación como C, se convierten en programas que pueden ser entendidos por la máquina a través de un **compilador** (que traduce todo el código de una vez) o un **intérprete** (que traduce línea por línea).

Compilador vs. Intérprete

El lenguaje C es compilado. Un compilador traduce el código fuente completo a lenguaje máquina, creando un archivo ejecutable optimizado. Esto resulta en programas muy rápidos, aunque el proceso de desarrollo requiere una compilación tras cada cambio.

2. Fundamentos del Programa en C

Un programa en C tiene una estructura básica y utiliza elementos fundamentales para manejar datos. El punto de entrada es siempre la función `main()`. Dentro de ella, usamos **variables** para almacenar datos, especificando su **tipo** (entero, decimal, carácter, etc.). También podemos definir **constantes** para valores fijos y usar **operadores** para realizar cálculos y comparaciones.

Tipos de Datos Principales en C

C maneja diferentes tipos de datos, cada uno ocupando un espacio distinto en memoria y permitiendo diferentes rangos de valores.

Tipos de Operadores

  • Aritméticos: Para realizar operaciones matemáticas (+, -, *, /, %).
  • Relacionales: Para comparar valores (==, !=, <, >, <=, >=).
  • Lógicos: Para combinar expresiones lógicas (&& AND, || OR, ! NOT).
  • Asignación: Para asignar valores a variables (=, +=, -=, etc.).
  • Incremento/Decremento: Para sumar o restar 1 a una variable (++ , --).

3. Estructuras de Control

Las estructuras de control nos permiten alterar el flujo secuencial de un programa, tomando decisiones y repitiendo acciones. Son la base para crear programas dinámicos y funcionales.

Estructuras de Selección (Decisión)

Estas estructuras permiten que el programa elija qué bloque de código ejecutar basándose en una condición.

if / if-else

Ejecuta un bloque de código si una condición es verdadera. `if-else` añade un bloque alternativo si la condición es falsa.

switch-case

Evalúa una variable y ejecuta un bloque de código (`case`) según su valor. Es ideal para múltiples opciones.

Estructuras de Repetición (Bucles)

Permiten ejecutar un bloque de código múltiples veces hasta que se cumpla una condición.

while

Repite un bloque mientras la condición sea verdadera. La condición se evalúa **antes** de cada iteración. Puede no ejecutarse nunca.

do-while

Repite un bloque mientras la condición sea verdadera. La condición se evalúa **después** de cada iteración. Se ejecuta al menos una vez.

for

Ideal para iterar un número conocido de veces. Agrupa la inicialización, la condición y el incremento en una sola línea.
